## Project Name
Sonata
## Description
Web app that combines sound files and lyric file and play it in sync

### Basic Features
 - Can add up to 3 audio files (WAV, MP3, and M4A, OGG, FLAC)
 - Can add 1 lrc file
 - Can control master volume
 - Can mute and solo play a sound track
 - Can display Lyrics from LRC file
 - Dark mode/light mode
### Basic Feature Limitations
 - Sound file size limit is 100mb
 - Can't control volume of each track
 - Ads (TBC)

### Pro Features
 - Unlimited sound files
  - it's up to your machine if can handle millions of sound file playing at the same time
 - Can control volume of each track individually
 - Combine and Export feature
  - If the user have one track muted, one track in 35% volume, and the other at 100% volume, the combining and export should capture that state
 - No ads (TBC)
